## Отложенные задачи
- Добавить в Playwright проект с экраном телефона и правило в CLAUDE.md «если менялся UI, e2e проходит
  на компьютере и на телефоне». Сделать вместе с этапом F-02.1 (каркас разделов): до него экран телефона
  не отличается от экрана компьютера.
- Убрать из `frontend/steiger.config.mjs` исключение для правила `fsd/typo-in-layer-name` (папки `src/_app`
  и `src/_pages`), когда выйдет `@feature-sliced/steiger-plugin` новее 0.8.2 с исправлением этого правила:
  сейчас оно считает слои с подчёркиванием опечатками. Проверка: убрать исключение и запустить `npm run lint`.
- Разобрать предупреждения `npm audit` во frontend/ — они были до перевода фронтенда на FSD. Приходят через
  `shadcn` (`hono`, `@hono/node-server`, `deepmerge`, `minimatch` через `ts-morph`) и `typescript-eslint`
  (`minimatch`). `npm audit fix --force` без проверки не запускать: он предлагает ломающие обновления.
