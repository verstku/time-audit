# Фичи

Порядок реализации — сверху вниз, по колонке «№». ID фичи не меняется и не используется повторно.

Статусы:
- идея — есть только эта строка;
- описана — подробное описание утверждено (docs/product/features/);
- в работе — часть этапов готова или по этапу идёт работа;
- готово — все этапы готовы.

## Почему такой порядок
- MVP — в порядке шагов из 10.1 описания продукта, без изменений. Шаг 1 — это F-01 и F-02, шаг 4 — F-05 и F-06.
- Внутри шага 4 записи времени идут раньше таймера: таймер создаёт записи и показывает результат в ленте дня и карточке задачи, а их делает F-05.
- Блоки экрана «Сегодня» делают те фичи, чьи правила они показывают: лента дня — F-05, «Что делаете?» — F-06, прогресс дня и балансы — F-07. F-08 добавляет итог по направлениям и собирает экран целиком.
- После MVP — порядок списков 10.2–10.5. Фичи, полученные разбиением одного пункта, стоят подряд на его месте. Зависимости соблюдены: каждая фича зависит только от фич выше неё.
- F-14 «Уведомления» — общая основа. Свои виды уведомлений добавляют фичи, которым они нужны: F-15, F-16, F-25, F-34.
- F-21 добавляет плотность и долю ценной работы сразу во все места, где показатели уже есть с MVP: «Сегодня», итоги месяца в Журнале, отчёты, архив месяцев.
- История прогресса материалов сохраняется с MVP (F-11). На ней в 1.0 держатся темп (F-27), «пройдено уроков и страниц» (F-23) и прогресс материалов в итогах недели (F-25).
- Адаптивная вёрстка — требование к каждой фиче, а не отдельная фича.
