# Глоссарий

Термины предметной области. В документах, спеках, интерфейсе и коде используем только их.
«В коде» — имя для кода (по-английски), одно и то же во всех файлах.

### Пользователь и настройки
| Термин | Что значит | В коде |
|---|---|---|
| Пользователь | Владелец аккаунта (email и пароль). Ведёт учёт только для себя и видит только свои данные | `user` |
| Гость | Посетитель без входа: страницы входа, регистрации, сброса пароля; с 1.0 — страницы для гостей | `guest` |
| День регистрации | День создания аккаунта. В этот день норма 0, норма считается со следующего дня | `registration_date` |
| Первый вход | Знакомство с приложением после регистрации (1.0). Четыре коротких шага, любой можно пропустить: часовой пояс и язык, вариант использования, рабочий график, первый таймер | `onboarding` |
| Вариант использования | Ответ на вопрос первого входа «Как вы будете пользоваться TimeAudit?»: «Учусь», «Работаю», «Фриланс», «Своё». От него зависят стартовые направления, типы работы и то, включён ли модуль «Обучение». Например, для «Учусь» создаются направления «Английский» и «Программирование», типы «Теория», «Практика», «Организационное», модуль «Обучение» включён | `usage_type`: `study`, `work`, `freelance`, `custom` |
| Настройки | Язык (RU/EN), тема (светлая, тёмная, как в системе), часовой пояс, первый день недели, формат времени и другие | `user_settings` |
| Часовой пояс | Определяется автоматически; по нему запись относится к дню | `timezone` |
| Первый день недели | С него начинается неделя для баланса недели. По умолчанию понедельник | `week_start` |

### Разделы и экраны
| Термин | Что значит | В коде |
|---|---|---|
| Экран «Сегодня» | Главный экран, открывается по умолчанию: фраза дня, прогресс дня, показатели, план на сегодня, лента дня, итог дня по направлениям | `today` |
| Журнал | Раздел истории по дням: календарь месяца, просмотр и правка любого дня, отметка особых дней, неделя таблицей | `journal` |
| Неделя таблицей | Вид Журнала (1.0): строки — направления, колонки — дни недели, в ячейках — время; итоги по строкам и колонкам, норма и баланс недели | `week_table` |
| Отчёты | Раздел аналитики за любой период: показатели, графики, итоги недель, архив месяцев, выгрузка | `reports` |
| Точность оценок | Блок отчётов (1.0): насколько в среднем факт отличается от оценки по выполненным задачам, отдельно по направлениям | `estimate_accuracy` |
| Выгрузка | Скачивание своих данных: записи за период и сводка по направлениям в CSV и Excel, а также все данные аккаунта (1.0); PDF-отчёт — с 2.0 | `export` |

### Классификация
| Термин | Что значит | В коде |
|---|---|---|
| Справочник | Список значений, который пользователь ведёт сам: направления, проекты, типы работы, метки, колонки доски. Базовые справочники создаются при регистрации на языке интерфейса | `catalog` |
| Направление | Область, которой человек занимается: «Английский», «Go», «Личное». Есть цвет, иконка, переключатель «Рабочее время»; можно архивировать | `area` |
| Вложенное направление | Направление внутри другого: «Программирование → Go». Уровней два | `area` с `parent_id` |
| Рабочее время (переключатель) | Признак направления верхнего уровня, по умолчанию включён: время по направлению входит в факт и баланс. Вложенные наследуют его | `is_working_time` |
| Нерабочее время | Время по направлениям с выключенным «Рабочим временем». Записывается, но в факт не входит; в отчётах показывается отдельно | `non_working_time` |
| Без направления | Задача, у которой не выбрано направление. Её время считается рабочим, в отчётах — отдельной строкой | `area_id` пустой (`null`) |
| Архивирование | Элемент справочника пропадает из списков выбора, история сохраняется | `is_archived` |
| Проект | Конкретная работа с началом и концом внутри направления: «WMS», «TimeAudit». Необязателен | `project` |
| Статус проекта | Активный, на паузе, завершён | `project_status`: `active`, `paused`, `completed` |
| Тип работы | Характер работы: «Теория», «Практика», «Организационное». Справочник пользовательский; базовый набор создаётся при регистрации | `work_type` |
| Ценная работа (флаг) | Признак типа работы для доли ценной работы. По умолчанию включён только у «Практики» | `is_valuable` |
| Метка | Дополнительная отметка, например инструмент: «Claude», «Terminal». У задачи или записи их может быть несколько | `tag` |

### Задачи
| Термин | Что значит | В коде |
|---|---|---|
| Задача | То, что нужно сделать. Направление, проект, тип работы по умолчанию и метки указываются в ней один раз | `task` |
| Статус задачи | «В очереди», «В работе», «На паузе», «Готово» и свои колонки доски | `task_status`: `todo`, `in_progress`, `paused`, `done` |
| Вид «Список» | Основной вид раздела «Задачи»: задачи сгруппированы по направлениям и проектам | `task_list` |
| Вид «Доска» | Вид раздела «Задачи» как в Jira: колонки по статусам, карточки перетаскиваются между колонками (1.0) | `task_board` |
| Колонка доски | Колонка вида «Доска». Базовые соответствуют статусам, можно добавить свои | `board_column` |
| Приоритет | Высокий, обычный, низкий | `priority`: `high`, `normal`, `low` |
| Срок | Дата, к которой нужно сделать задачу (необязательно) | `due_date` |
| Оценка | Сколько времени, по мнению пользователя, займёт задача (необязательно) | `estimate` |
| Время задачи | Сумма длительностей всех записей задачи за всё время. В паре «план и факт» это и есть «факт» — не путать с фактом для баланса | `time_spent` |
| План и факт | Сравнение оценки и времени задачи: «Оценка 3:00 · Факт 4:10 · +1:10 (139%)» | `estimate` / `time_spent` |
| Чек-лист | Список подзадач внутри задачи | `checklist_item` |
| Постоянная задача | Задача для регулярных занятий, которая не закрывается («Английский — слова»). По выбранным дням сама появляется в плане на сегодня | `is_ongoing`, дни — `repeat_days` |
| Сделано сегодня | Отметка постоянной задачи в плане на сегодня; на следующий день сбрасывается | `done_today` |
| Повторяющаяся задача | (2.0) После выполнения создаётся следующий экземпляр: «Еженедельный разбор» | `recurrence` |
| План на сегодня | Список задач, которые пользователь собирается сделать сегодня | `daily_plan`, строка — `plan_item` |
| Корзина | Удалённые задачи и материалы; лежат 30 дней (с 1.0) | `trash`, `deleted_at` |

### Таймер и записи
| Термин | Что значит | В коде |
|---|---|---|
| Таймер | Идущий отсчёт времени по одной задаче. У пользователя он один и хранится на сервере | `timer` |
| Панель таймера | Полоса с идущим таймером и кнопками, видна на любом экране | `timer_bar` |
| Запись времени | Один отрезок работы над одной задачей; создаётся таймером или вручную | `time_entry` |
| Длительность | От старта до остановки минус паузы, в целых минутах, не меньше 1 минуты. Главная цифра записи | `duration` |
| Время начала и конца | Заполняются таймером; у ручной записи необязательны | `started_at`, `ended_at` |
| Дата записи | День по местному времени, к которому относится запись | `date` |
| Запись без времени | Ручная запись, у которой есть только длительность | `time_entry` без `started_at` |
| Пауза | Промежуток внутри записи, когда отсчёт остановлен. Записывается | `pause` |
| Способ создания | Таймер или вручную | `source`: `timer`, `manual` |
| Заметка | Короткий текст к записи: что конкретно сделано | `note` |
| Переключиться | Одним действием сохранить текущую запись и запустить таймер на другой задаче | `switch` |
| Сбросить | Отменить идущую запись, если таймер запустили случайно | `discard` |
| Разделить запись | Сделать из одной записи две, отнеся часть минут к другой задаче | `split` |
| Пересечение | Записи, которые пересекаются по времени | `overlap` |
| Лента дня | Все записи дня по времени; паузы и простои — серые промежутки между ними | `day_timeline` |
| Итог дня по направлениям | Цветная полоса долей и список «Go 3:10 · Английский 1:00» | `day_summary` |

### Норма и баланс
| Термин | Что значит | В коде |
|---|---|---|
| Рабочий график | Норма часов по дням недели. По умолчанию пн–пт по 8 ч, сб–вс по 0 ч | `work_schedule` |
| Норма | Сколько часов нужно отработать за день или период | `norm` |
| Особый день | Дата или период с нормой 0: «Выходной», «Отпуск», «Больничный», «Праздник», «Перерыв в учёте». Работа в такой день засчитывается в факт | `special_day`; виды — `day_off`, `vacation`, `sick_leave`, `holiday`, `tracking_break` |
| Перерыв в учёте | Вид особого дня для периода без учёта; с 1.0 приложение само предлагает его после перерыва | `tracking_break` |
| День без нормы | День с нормой 0: по графику, особый день или день регистрации. Всё время в такой день идёт в плюс | `is_zero_norm` |
| Закрытый день | Прошедший день, до вчера включительно. Сегодняшний день закрывается в полночь | `closed_day` |
| Факт (отработано) | Время записей по рабочим направлениям, включая выходные и особые дни | `worked` |
| Баланс | Факт − норма: «+3:15» (переработка) или «−6:40» (недоработка). Считается за неделю и за месяц | `balance` |
| Подсказка на сегодня | «Чтобы закрыть неделю в ноль, сегодня нужно ещё 4:00» | `today_needed` |
| Прогноз месяца | «Чтобы закрыть месяц в ноль, в оставшиеся 12 рабочих дней нужно в среднем 8:40 в день» | `month_forecast` |
| Архив месяцев | Таблица итогов всех прошлых месяцев | `month_archive` |
| Календарь месяца | Вид Журнала: по ячейке на день, с отработанным временем и цветом выполнения нормы | `month_calendar` |

### Показатели эффективности
| Термин | Что значит | В коде |
|---|---|---|
| Выполнение нормы | Факт / норма × 100% | `norm_completion` |
| Плотность работы | Время в работе / (время в работе + простои) × 100% | `density` |
| Время в работе | Длительность рабочих записей (для расчёта плотности) | `active_time` |
| Простой | Пауза таймера или промежуток между рабочими записями короче порога | `idle_time` |
| Порог простоя | Граница между простоем и «вне работы». По умолчанию 60 минут | `idle_threshold` |
| Вне работы | Пауза или промежуток длиннее порога; в плотность не входит | `off_work` |
| Доля ценной работы | Время ценных типов / всё рабочее время × 100% | `valuable_share` |

### Обучение
| Термин | Что значит | В коде |
|---|---|---|
| Обучение | Модуль с материалами и учебными планами; можно выключить в настройках | `learning` |
| Материал | Источник знаний: книга, курс, видео, статья | `material` |
| Вид материала | Книга, видеокурс, видео или плейлист, статья, интерактивный курс, другое | `material_kind`: `book`, `video_course`, `video`, `article`, `interactive_course`, `other` |
| Статус материала | «В очереди», «Текущий», «На паузе», «Пройден», «Брошен» | `material_status`: `todo`, `current`, `paused`, `completed`, `dropped` |
| На досуге | Отметка материала: он не обязателен к прохождению и не участвует в учебном плане | `is_leisure` |
| Структура материала | Разделы и элементы или просто число страниц | `material_section`, `material_item` |
| Раздел | Часть структуры: модуль курса, часть книги | `material_section` |
| Элемент | Глава книги или урок курса | `material_item` |
| Позиция («где остановился») | Страница, урок, минута внутри видео | `position` |
| Прогресс материала | Доля пройденного: по страницам, урокам или минутам видео | `progress` |
| Время материала | Сумма времени всех задач, связанных с материалом | `time_spent` |
| Темп | Средний прогресс в неделю за последние 14 дней работы с материалом | `pace` |
| Прогноз окончания | Остаток / темп: «При текущем темпе — 12 декабря» | `finish_forecast` |
| «Докуда дошли?» | Окно после остановки таймера на материале: страница, урок, минута | `progress_prompt` |
| Учебный план | План прохождения материалов по этапам | `study_plan` |
| Этап учебного плана | «Этап 1 — База», «Этап 2 — Углубление»; внутри — материалы по порядку | `study_stage` |

### Мотивация, итоги, уведомления
| Термин | Что значит | В коде |
|---|---|---|
| Мотивационная фраза | Короткий текст для настроя на работу | `phrase` |
| Фраза дня | Фраза, которая показывается при первом открытии приложения за день | `daily_phrase` |
| Источник фразы | Базовая коллекция (общая для всех, поставляется с приложением), личная коллекция пользователя, ИИ (2.0) | `phrase_source`: `base`, `personal`, `ai` |
| Итоги недели | Автоматическая сводка за прошедшую неделю; хранится в архиве | `weekly_summary` |
| Уведомление | Сообщение внутри приложения, в браузере или установленном приложении | `notification` |
| Напоминание | Уведомление таймера: долгий таймер, долгая пауза, таймер не запущен | `reminder` |
| Тихие часы | Время, когда уведомления не приходят | `quiet_hours` |
| Быстрый поиск и команды | Окно по Ctrl+K: поиск задач, материалов, записей и команды | `command_palette` |
